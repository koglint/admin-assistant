Restricted Tools

Use this area only for protected maintenance actions. Access stays locked behind the approved account and backend password checks.

Admin Password

Sign in with an approved email, then enter the backend admin password to unlock protected actions on this page.

Protected Actions

These actions only run through the backend after the approved user and password checks pass. Use the full reset only when the whole Firestore dataset should be cleared.

Add Student Exception

Prevents one student ID from receiving detentions or appearing in reports. Existing student and attendance-day records for that ID are removed.

Purge One Student

Deletes one student document, matching attendance-day records, and any exception marker for that student ID.

Purge ALL Data

Deletes every student, attendance-day, upload-tracking, and exception-list record from Firestore.

Enter a student ID, then type the same ID again to confirm adding this student to the exception list.

Enter a student ID, then type the same ID again to confirm deleting only that student's Firestore records.

Type DELETE to confirm that all student data should be removed.
