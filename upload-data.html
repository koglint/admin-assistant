Upload Workflow

Use the blue daily upload for morning late arrivals. Use the green confirmation upload for full-day or weekly data after detention rolls have been marked.

Upload File

Blue daily upload: use today's morning Sentral absence export, after Period 2 and before first break detention. This records late arrivals and assigns detentions.

Green confirmation upload: use full-day or full-week absence data when attendance evidence needs to be stored. It does not create or resolve detention debt.

Sentral path: Sentral -> School Attendance -> Reports -> Absence Lists -> Export.

File type: upload the Sentral .xls absence export.

Order matters: upload morning lates, then use the detention roll to clear outstanding detention debt when students serve detention.

Late detection: only missed roll-call rows after 8:35AM are treated as late arrivals.
